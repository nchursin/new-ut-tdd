### Флип: Проблематика
![ai meme](assets/ai_meme_2.png)
  
- LLM галлюцинирует
- LLM часто забегает вперед
- LLM может выдавать код огромными кусками
- Есть искушение довериться тому, что примерно похоже на результат 
  
![ai meme](assets/ai_meme_3.png)
### Флип: LLM + TDD
- Задать TDD как базовый принцип разработки
- Создать план в виде тестов
- Агент итерируется по плану, который расписан в виде тест-кейсов
- Тест описывает ЧТО, код описывает КАК (можно даже разделить на уровне агентов)
- Ревьювить после каждого зелёного теста (можно реже — зависит от уровня доверия)
- Коммитить как можно чаще, чтобы было куда откатиться

## Проектор: Демо. Упражнение про кассовый чек

```  
Наименование товара         Кол-во         Цена            Стоимость   
  
Ноутбук                       2        45000.00 руб       90000.00 руб
Мышь                          3         1500.00 руб        4500.00 руб
......................................................................
Итого                                                     94500.00 руб
Скидка 15%                                               -14175.00 руб
Налог NV 8.0%                                             +6426.00 руб
......................................................................
Общая сумма                                               86751.00 руб
```  

Мы производим кассовый аппарат, способный выдавать чеки.
Принимает от пользователя 4 параметра для одного или нескольких товаров:
 - Название
 - Количество 
 - Цена
 - Буквенный код штата

По общей цене без налога мы можем рассчитать скидку.                          
| Сумма заказа | Ставка скидки |
| --- | --- |
| > 1000 | 3% |
| > 5000 | 5% |
| > 7000 | 7% |
| > 10000 | 10% |
| > 50000 | 15% |

По заданным 2-буквенным кодам штата мы можем рассчитать ставку налога.
| Штат | Ставка налога |
| --- | --- |
| UT | 6,85% |
| NV | 8,00% |
| TX | 6,25% |
| AL | 4,00% |
| CA | 8,25% |
