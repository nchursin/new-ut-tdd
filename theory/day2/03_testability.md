## Какой код тестируемый?
- immutable объекты
- разделение Command / Query
- маленькие модули
- низкая связность
- единая отвественность модуля
- DI (dependency injection) все зависимости передаются извне
- детерменированность, код выдает одинаковый результат (постоянное - в конструктор, транзиентное - в параметр)
