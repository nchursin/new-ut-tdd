# Качество тестов: DSL
Timing: 45-60 min

Мы сделали проще и легче с фикстурами. Но тесты всё ещё оечнь технические. Как сделать так, чтобы тесты стали вашими требованиями и все в вашей команде могли читать их?

### Польза DSL
- Тесты становятся читаемыми для любого, кто знаком с предметной областью
    - Общий язык
- Тесты легко писать
    - Create. подскажет какие сущности есть в вашем домене
    - Create.Entity() создаст валидную сущность
    - Create.Entity(). подскажет как можно параметризовать сущность
    - Скрытие данных: в тесте только то, что важно для теста
    - Легко расширять по аналогии

### Практика
#### Упражнение про кассовый чек

Мы производим кассовый аппарат, способный выдавать чеки.
Принимает от пользователя 4 параметра для одного или нескольких товаров:
 - Название товара
 - Количество товара
 - Цена товара
 - Буквенный код штата
   
По заданным 2-буквенным кодам штата мы можем рассчитать ставку налога.
По общей цене без налога мы можем рассчитать скидку.
  
**Пример чека:**
  
Наименование товара А  | Количество |  Цена за единицу |  Общая стоимость
  
Наименование товара  Б |  Количество |  Цена за единицу |  Общая стоимость
  
-----------------------------------------------------
  
Итого без налогов                             XXXXX
  
Скидка X%                                       -YYY
  
Налог Y%                                           +ZZZ
  
-----------------------------------------------------
  
Общая сумма                                    XXXXXX
| Сумма заказа | Ставка скидки |
| --- | --- |
| > 1000 | 3% |
| > 5000 | 5% |
| > 7000 | 7% |
| > 10000 | 10% |
| > 50000 | 15% |
  
| Штат | Ставка налога |
| --- | --- |
| UT | 6,85% |
| NV | 8,00% |
| TX | 6,25% |
| AL | 4,00% |
| CA | 8,25% |
